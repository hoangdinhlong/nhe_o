# Core Business Rules (Catalog)

Authoritative index of key domain rules, database invariants, binary storage formats, and formal verification policies in **Nhé O** (`nhe_o` / `Nhe_O`).

### Domain Specifications Index
- [`storage-and-wal-format.md`](storage-and-wal-format.md) — Exact binary byte layouts and CRC32 invariants for 4,120-byte `"NHEO"` WAL frames (`WAL_Frame_Kind`), 4,096-byte `"SLOT"` primary slotted pages, 16-byte inline `TOAST_Pointer` + 4,096-byte `"TOAS"` overflow pages, 4,096-byte `"BTRE"` B+Tree node pages, and 4,096-byte `"KVMG"` durable KV WAL pages.

| `BR-005` | Dual-Mode Pub/Sub Delivery, `Owner_Tx` Guard & Overflow Accounting | Standard channels deliver messages in FIFO order immediately to matching active subscribers (exact channel or general `*` glob wildcard pattern at any position, `R3-MED-05`) in bounded ring buffers, incrementing `Dropped` if a subscriber's ring is full. `Durable` transactional notifications (`Stage_Notify`) verify `Staging.Owner_Tx = Ctx.Id` and are dispatched to subscribers iff `Ctx.State = Tx_Committed` (`Flush_Committed_Notifications`), or discarded by the owning transaction on `Rollback_Tx`. | `src/nhe_o-pubsub.ads`, `src/nhe_o-transaction.ads` |
